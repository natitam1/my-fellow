## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues, pull requests, or public forums.**

Instead, please report vulnerabilities privately through **GitHub Security Advisories**:

1. Navigate to the **Security** tab of the `my-fellow` repository on GitHub.
2. Click **Report a vulnerability** to open a draft advisory.
3. Provide a detailed summary including:
   - Type of issue (e.g., authentication bypass, injection, data leakage).
   - Affected application component (`apps/mobile`, `apps/api`, etc.).
   - Step-by-step reproduction instructions or proof-of-concept.
   - Potential impact of the vulnerability.

Our maintainers will review the submission, acknowledge receipt within 48 hours, and coordinate a fix and release disclosure timeline.
